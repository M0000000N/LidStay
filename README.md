# LidStay

**닫아도, 작업은 계속.** macOS 메뉴바에서 사용하는 한국어 잠자기 방지 앱입니다.

## [⬇ LidStay 무료 다운로드](https://github.com/M0000000N/LidStay/releases/latest/download/LidStay-macOS.zip)

macOS 14 이상 · Apple Silicon 및 Intel 지원 · Developer ID 서명 및 Apple 공증 완료

## 설치

1. 위 링크에서 ZIP 파일을 내려받고 압축을 풉니다.
2. `LidStay.app`을 **응용 프로그램** 폴더로 옮기고 실행합니다.
3. 메뉴바의 노트북 아이콘을 눌러 **잠자기 방지 시작**을 선택합니다.
4. 첫 사용 시 macOS 관리자 인증 창에서 보조 프로그램 설치를 승인합니다.

## 주요 기능

- 메뉴바에서 잠자기 방지 시작·종료
- 타이머 없이 실행하거나 종료 시간 설정
- 충전기를 연결하지 않은 상태에서도 실행
- 배터리가 설정한 잔량에 도달하면 잠자기 방지 종료 — 기본값 20%
- 로그인 시 앱 자동 실행
- macOS 라이트·다크 모드 지원

인터넷 연결·계정 가입은 필요하지 않습니다. 로그인할 때 앱이 자동으로 열리며, 잠자기 방지는 직접 시작합니다.
